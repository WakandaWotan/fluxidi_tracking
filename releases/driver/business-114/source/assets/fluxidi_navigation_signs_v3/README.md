# Fluxidi Navigation Signs v3

Volledig opnieuw opgebouwde vectorfamilie.

- 34 manoeuvres
- 4 talen: NL, EN, FR en ES
- 136 afzonderlijke transparante PNG-bestanden
- 34 bewerkbare SVG-masterbestanden
- manifest.json en manifest.csv
- Flutter asset resolver
- controlebladen per taal

Rotondes:
1e afslag = rechts
2e afslag = rechtdoor
3e afslag = links
4e afslag = terugkeren

T-splitsingen gebruiken de normale korte instructies:
linksaf, rechtdoor of rechtsaf.
